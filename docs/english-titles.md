# English display names

The English view uses `Le Dang Dai Trang` (uppercase where the existing design uses uppercase). Vietnamese names remain unchanged in the Vietnamese view.

Use a verified English release title when available; otherwise remove Vietnamese diacritics from the existing title, including Đ/đ → D/d. Do not invent translations. The change is display-only: IDs, URLs, source data, artwork, release dates, sorting and categories stay the same. Text inside existing poster/video artwork remains original.

## Unverified English names

Other archive titles retain their original wording without Vietnamese accents. Existing English titles (e.g. `ALL EYES ON US`, `NIVEA MEN SILVER PROTECT`) remain unchanged. A campaign slogan translation alone is not treated as a confirmed title for an individual film.

The production studio lists its Generali / Ensure branded films under their Vietnamese titles: [30 Pictures branded short films](https://30pictures.com/advertising/branded-short-film). The original [Vũ điệu tình yêu upload](https://vimeo.com/759819854) also uses its Vietnamese title. These use romanization until an English release title is supplied or verified.
